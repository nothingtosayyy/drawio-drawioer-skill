# agents/ — 接口声明

本目录存放面向 Agent 客户端平台的接口声明文件。

| 文件 | 说明 |
|---|---|
| `openai.yaml` | 为支持 agent interface 规范的客户端提供三项信息：显示名（Research Draw.io Diagram Builder）、一句话简介、默认提示词（default_prompt）。默认提示词会引导客户端**先询问保真级别（L1/L2/L3）与迭代预算**，再进入 规划 → 预检 → 本地预览 → 截图审查 → 预算内迭代 的标准流程。 |

## 说明

- 该文件只影响客户端侧的呈现与默认开场行为，不改变技能的实际行为规范。
- 技能的完整行为规范以根目录 `SKILL.md` 为准（入口分级、门禁矩阵、工作流与失败降级均定义在那里）。
